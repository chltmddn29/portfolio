회의 녹음을 AI가 회의록으로 자동 변환해주는 서비스

Live Demo 새 탭에서 열기 ↗

Overview

회의를 녹음하면 AI가 음성을 인식해 회의록(문서)으로 자동 정리해주는 웹 서비스입니다. 업로드한 오디오는 백엔드에서 화자 분리 및 STT(음성 인식)를 거쳐 텍스트로 변환되고, 요약된 회의록을 문서(DOCX/PDF) 또는 노션 페이지로 내보낼 수 있습니다.

Tech Stack

Frontend
Flutter Web Riverpod go_router Dio
Backend
FastAPI SQLAlchemy Groq (STT/LLM) pyannote.audio (화자 분리) python-docx / reportlab Notion API
Infra
Vercel Hugging Face Spaces (Docker) Supabase PostgreSQL

Architecture

Frontend (Flutter Web, Vercel 배포) → Backend (FastAPI, Hugging Face Spaces Docker) → DB (Supabase PostgreSQL)

업로드된 오디오는 백엔드에서 스트리밍으로 저장되고, ffmpeg으로 청크 변환 후 Groq API로 STT/요약을 수행합니다. 변환 파이프라인은 화면 밖에서도 끝까지 진행되도록 별도 provider로 분리되어 있어, 사용자가 페이지를 이동해도 작업이 중단되지 않습니다.
