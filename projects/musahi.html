musahi (무사히)

재난문자를 관심지역 기준으로 실시간 수신하고, 대피소·안전연락처 정보를 제공하는 재난 안전 Flutter 앱

GitHub 저장소 ↗

Overview

사용자가 등록한 관심지역을 기준으로 재난문자를 실시간으로 수신하고, 대피소·안전연락처 정보와 상황별 행동요령을 제공하는 앱입니다. 서버가 행정안전부 재난안전데이터공유플랫폼에서 재난문자를 주기적으로 수집해 심각도와 지역에 따라 FCM 토픽으로 발행하면, 클라이언트는 관심지역 설정에 맞는 토픽을 구독해 알림을 받습니다.

Tech Stack

Client
Flutter go_router firebase_core cloud_firestore firebase_messaging (FCM) Dio shared_preferences
Server
Firebase Functions (Node.js/TypeScript) 재난안전데이터공유플랫폼 API SGIS Open API Cloud Firestore Cloud Messaging

Architecture

Flutter 앱은 core(공통 상수·라우팅·알림 동기화·전역 설정)와 features(재난문자·설정/관심지역·대피소·행동요령·홈) 레이어로 나뉘고, 각 feature는 model / repository / presentation 하위 레이어로 구성됩니다.

Firebase Functions가 재난문자를 주기적으로 수집해 Firestore에 저장하고, 심각도·지역별로 FCM 토픽을 발행합니다. 클라이언트는 SGIS 행정구역 검색으로 등록한 관심지역을 실제 수신지역과 매칭해 가장 세분화된 지역(없으면 상위 시군구·시도) 기준으로 토픽을 구독하며, 설정 변경 시 즉시 구독/해제에 반영되고 동기화 실패 시 재시도합니다.
