LI-ON

대덕소프트웨어마이스터고등학교 학생을 위한 자격증 AI 학습 로드맵 Flutter 앱

GitHub 저장소 ↗

Overview

자격증 탐색부터 AI 학습 로드맵, 학습 일정, 자료 관리까지 한곳에서 처리할 수 있는 앱입니다. 키워드·카테고리로 자격증을 탐색하고 북마크할 수 있고, AI와의 대화형 로드맵을 통해 학습 계획을 세운 뒤 캘린더에 바로 일정으로 추가할 수 있습니다. 학습 자료는 별도 자료방에서 목록·필터·상세 보기로 관리합니다.

Tech Stack

Client
Flutter Riverpod go_router (StatefulShellRoute) Dio flutter_secure_storage json_serializable

Architecture

기능(feature) 단위로 나누고, 각 기능 내부를 data와 presentation으로 분리하는 MVVM + Repository 구조입니다. 의존 방향은 presentation → data → core로 고정되어 있고, 두 기능 이상에서 쓰는 코드만 core로 올립니다.

로그인 이후에는 탐색·로드맵·자료방·캘린더·프로필 5개 탭을 공유하는 하단 내비게이션(StatefulShellRoute)을 사용하고, 모든 화면은 Http*Repository를 통해 실제 REST API 서버와 통신합니다.
